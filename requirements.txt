#      (src/auth/service.py). pyproject.toml correctly lists only pyjwt.
#   2. It omitted psycopg2-binary, which pyproject includes for Alembic's
#      synchronous migration engine.
#   3. Several entries carried no version floor at all (`bcrypt`, `PyJWT`,
#      `pydantic[email]`), so a resolver was free to pick anything.
#
# Two hand-maintained dependency lists will always drift. One list cannot.
